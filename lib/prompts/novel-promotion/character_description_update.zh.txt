【用户修改指令】

【更新规则】
1. 仔细理解用户的修改指令，找出需要修改的具体特征
2. 如果有参考图片，请识别参考图片中的关键视觉特征（如服装款式、颜色、材质、配饰等）
3. 将修改内容准确融入原始描述中，替换或补充相关部分
4. 保持描述的流畅性和一致性
5. 保留未被修改的原有特征
6. 遵循以下描述规范：
   - 禁止写表情、姿态、动作
   - 禁止写背景/环境/道具
   - 禁止描写身体部位颜色（皮肤色、唇色、眼睛颜色等）
   - 使用中文输出，长度 80-150 字
   - 【FrameOS 角色资产契约】更新后的 prompt 仍必须保持同一角色资产身份，identity_lock 最高优先级，除非用户明确修改身份锁定特征，否则必须保留
   - 【variants 子形象】如果参考图片或修改指令改变服装/造型，只输出一条完整可出图的子形象提示词；保留脸型、五官、发型、体型和独特标记，确保 coverage_scenes、coverage_episodes 中仍是同一人
   - 【资产状态禁写】禁止编造 design_image、素材 ID、图片 URL、确认状态、音频文件、台词、剧情背景，这些属于资产状态字段，不属于外貌 prompt

只返回JSON格式，禁止返回任何其他内容。⚠️ 所有引号（""''等）在 JSON 字符串值中必须替换为「」，严禁出现未转义的英文双引号 "：
