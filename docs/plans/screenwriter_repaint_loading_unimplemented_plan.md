## 目标

在已完成的编剧工作台与剧本转绘链路基础上，补齐前端跳转加载态和未实现功能的可用性约束，避免页面在异步数据返回前使用默认值渲染导致闪烁，同时让暂未接入的入口明确不可点击。

## 相关细节

1. Loading 页面
   - 编剧工作台进入新建剧本转绘、继续剧本转绘任务、切换剧本转绘阶段等页面跳转时，先进入 loading 页面。
   - Loading 页面只展示页面骨架，具体业务内容使用灰色矩形占位，不渲染默认任务名、默认剧本文本、默认阶段数据或 mock 业务内容。
   - 页面在拿到真实任务详情、任务列表或创建结果前，不应根据默认值渲染最终页面内容。

2. 剧本转绘链路范围
   - 入口页 `/screenwriter` 中，“剧本转绘 2.0”继续可用。
   - `/screenwriter/script-repaint` 新建任务页中，仅保留当前已实现的粘贴文本创建流程。
   - 剧本转绘任务详情、源设定、目标设定、逐集转绘、目标剧本页面都应在数据未就绪时展示骨架。

3. 未实现功能
   - 编剧工作台除“剧本转绘 2.0”以外的模式入口全部设置为不可互动。
   - 新建剧本转绘任务页中，“上传文本”“从工作台选择”等未实现源剧本输入方式不可互动。
   - 页面内其他未实现按钮如重新生成、保存编辑、进入后续分镜/生产链路等，统一禁用并在鼠标悬浮时显示“功能尚未实现”。
   - 禁用按钮保留可感知的视觉状态，不触发路由跳转、API 请求或本地状态推进。

4. 实现约束
   - 不修改 `docs/architecture.md`。
   - 优先复用现有 `screenwriter` 组件、路由 helper 和 Vitest 测试结构。
   - 新增公共 loading/disabled helper 时，应控制作用域在编剧工作台模块内，避免影响其他工作台页面。

## 完成标准

1. 编剧工作台进入剧本转绘相关页面时，先展示 loading 骨架，且骨架不包含默认业务值。
2. 剧本转绘详情及阶段页面在数据未加载完成前只展示骨架，不渲染默认任务内容。
3. 除剧本转绘以外的编剧工作台功能入口不可点击，hover 提示为“功能尚未实现”。
4. 新建剧本转绘任务页未实现的“上传文本”“从工作台选择”等入口不可点击，hover 提示为“功能尚未实现”。
5. 相关单元或系统测试覆盖 loading 骨架、未实现入口禁用与 tooltip 行为。
