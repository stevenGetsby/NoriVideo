# 画布交互与发布交接

## 已验证的交互

- 桌面画布用 Ctrl（Mac 可用 ⌘）加滚轮缩放。中键拖动、空格加左键平移，H 切换抓手工具，V 返回选择，Ctrl/⌘+0 适应画布。拖动期间屏蔽滚轮；中键松开后保留 200ms 防误触窗口。快捷键入口在左下角。
- 左侧工具栏和左上角项目菜单保持浮动。默认 50% 不透明，悬停或键盘聚焦时完整显示，项目菜单展开时也完整显示。不要为它们加通高背景或固定占位。
- 窄屏使用 100% 界面比例、动态视口高度和贴底提示词编辑器。移动端优先验证项目栏、积分、提示词框和底部控件。Chrome 的 iPhone 尺寸模拟可检查布局，真机上需另测地址栏和软键盘。
- 参考素材多时只显示少量缩略图和发送摘要。管理引用可搜索、筛选、批量暂停和恢复。传参预览为独立只读视图。暂停与断线相互独立。
- 放大模式按浏览器标签页和节点记住开关。图片移出即关闭，音频悬停播放、移出暂停。浏览器可能要求页面先有一次用户交互。
- 同一画布的新同类生成节点继承最近修改的参数，素材和正文留在原节点。视频统一前置提示词从文本节点右键菜单设置。

## 开发验证

- 用 `tests/browser/canvas-demo.mjs` 和合成资产复现，再跑 `tests/browser/canvas-reference-preview.browser.mjs` 和 `tsc --noEmit`。生成请求测试用拦截响应，避免真实任务与计费。
- 尺寸问题同时检查面板、正文输入层和高亮层。聚焦选择器可能比普通选择器优先级更高，曾导致编辑层仍被 260px 上限截断。

## 发布与换机恢复

- 仅使用仓库规则指定的备案机。候选镜像先在隔离端口预检，通过后短暂停止接收新生成任务，等已有任务结束再切换。核对 app、admin 健康状态及镜像提交，确认生成入口恢复，执行固定 TOS 上传、读取和删除探测。
- 保留生产环境文件和服务配置，禁止把密钥、真实素材或提示词复制到交接材料。SSH 偶发断开时先查当前阶段，避免重复启动发布单元。
- 换机时先读本页，再用生产镜像的 `org.norivideo.upstream-commit` 确定线上基线。最新发布资料目录位于备案机 `/opt/norivideo/releases/`，每版的 manifest 记录源码提交和归档摘要。
