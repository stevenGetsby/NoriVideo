## 先说结论

不是「把渐变换成纯色」就会高级。当前 UI 的问题主要是：**内容主角不突出、界面装饰比作品更有存在感、品牌视觉和交互语言没有形成独有记忆。**

我的优先推荐：

- **想让整个产品既高级又有辨识度：选 01「叙事编辑部」。** 它不是千篇一律的 AI 工具，而是「故事与创作的品牌」。
- **想突出互动影游内容、做未来内容平台：选 02「暗夜画框」。** 比 LibTV 更聚焦作品、更少工具感。
- **想让创作工具长期好用：选 03「创作操作系统」。** 清晰、轻松、适合高频工作。
- **04「蓝猫信号台」**适合品牌传播、宣发和活动，不建议原样铺满所有管理页。
- **05「下一幕」**适合互动作品详情、专题、剧情宣发，不建议成为高密度工作台的默认布局。

**可采用统一品牌、分场景实现**：01 为品牌首页 / 02 为影游内容平台 / 03 为 B 端创作工作台 / 04 为活动视觉 / 05 为剧情专题。不是五套混用，而是共享同一套排版、控件、内容结构后的五个使用场景。

## 一、现状与 LibTV 审计

### 当前 UI

已看页面：当前官网首页、作品库、互动影游 hub、影游总览，以及既有「片场」设计稿（均通过本地无头截图 `test-results/gallery` 查看，未打开线上页面）。

| 现状 | 问题 | 优化方式 |
|---|---|---|
| 官网首页首屏为暗紫底、电视 UI、插画猫和大面积氛围光 | 看起来仍是「AI 工具宣传页」，用户看不到真实作品和互动体验 | 首屏直接出现作品封面、故事名字、可玩的入口 |
| 作品卡大量使用彩色字母和无真实内容的封面 | 内容少时画面是「装饰性色块」，不像片库 | 使用真实封面 / 分镜帧；没有封面时采用固定构图的品牌占位，不伪造作品 |
| 工作台卡片、标签、按钮和侧栏都较重 | 主次不清，注意力被容器分走 | 降低容器存在感，用排版、间距、分组表达层级 |
| 品牌蓝猫与紫粉光效同时承担记忆点 | 记忆点分散，蓝猫更像贴纸 | 使用蓝猫蓝作为「信号色」，其余由作品内容提供颜色 |
| 首页、创作端、影游端叙事语言不同 | 用户感知不到「从灵感到作品再到观众」的完整链路 | 统一「发现—进入—选择—继续—创作」的动词与结构 |

当前 `src/styles/lanmiao-home.css` 中首页仍有 20 处渐变；`src/styles/frameos-replica.css` 虽已将主要品牌渐变 token 改为纯色别名，但作品封面等局部仍有渐变。仅删除 CSS 并不能解决视觉问题，需要整体确定内容层级。

### LibTV 值得借鉴的点

已查看 `test-results/libtv-reference/interface.png`：

1. **作品在首屏**，而不是大段介绍 AI 能力。
2. **创作入口非常明确**：「开始创作」与提示输入区处于视觉中心。
3. **顶部导航轻，主要内容大**，没有复杂侧栏占空间。
4. 轮播横幅让内容有「正在发生」的感觉。

不应照搬：深色底 + 荧光描边 + 大量玻璃按钮仍较接近通用 AI 产品。我们应在「作品先行、入口直接」之上，形成更有编辑审美的语言。

## 二、五套设计说明

### 01 叙事编辑部 / The Editorial

**关键词：电影杂志、文艺策展、错位网格、留白。**

- 象牙白 `#F2F0E9`、墨绿黑 `#20221E`、朱砂橙 `#DF4B2D`。
- 中文标题用宋体气质，正文用无衬线；宋体只用于大标题，不用于小字号操作。
- 大幅作品图片 + 克制的作品信息；卡片不套层层圆角。
- 错位网格让页面像一本编辑过的刊物，而不是自动堆出来的列表。
- 适合：官网、编辑精选、创作者故事、专题内容。
- 注意：首页仍需要一个高可见「开始创作」，不能让文艺排版牺牲转化。

### 02 暗夜画框 / The Cinema

**关键词：沉浸、作品先行、影院排片、成熟。**

- 暖黑 `#151515`、米白 `#EFEEE8`、浅青柠 `#E8EDAB`。
- 无紫色、无光晕；靠大幅真实影像形成高级感。
- 首屏左侧大作品，右侧「继续观看」与作品信息，结构简洁。
- 适合：影游内容平台、小程序首页、作品库、发行宣发。
- 注意：需要足够好的封面与帧图；没有媒体时不能靠彩色渐变伪造质感。

### 03 创作操作系统 / The Studio OS

**关键词：清晰、轻松、高效、真实创作流。**

- 暖灰 `#E8E6DF`、纸白 `#F7F5EE`、工具蓝 `#4156D9`。
- 不是传统深色后台：大面积浅色让长时间创作更舒适。
- 左侧轻导航，中间「继续创作 + 灵感输入 + 最近作品」，一个屏幕说明该做什么。
- 操作尺寸、筛选、状态、时间全部以效率为先。
- 适合：创作者首页、工作台、项目管理、素材管理。
- 注意：画布内部可以保持深色专注模式，与工作台的管理视图分开，不强求全局浅色。

### 04 蓝猫信号台 / The Broadcast

**关键词：电视频道、硬色块、海报、年轻。**

- 柠檬黄绿 `#E5F06D`、蓝猫信号蓝 `#1C43C9`、黑色 `#191B18`。
- 硬边框、错位海报、直给的「别只看。进来玩。」。
- 有传播性，也最能从众多 AI 产品中跳出来。
- 适合：品牌发布、活动页、宣发专题、社交媒体视觉。
- 注意：黄色大面积用于长期工作会疲劳；落到生产环境可缩小黄色面积，保留频道编号、蓝色和版式。

### 05 下一幕 / The Storyboard

**关键词：分镜、剧情推进、节奏、极简。**

- 纯白 `#F7F7F5`、黑 `#191919`、剪辑红 `#D94336`。
- 每张作品是一幕：编号、画面、故事钩子、进入按钮。
- 让「看内容」具备剧情节奏，天然契合互动影游。
- 适合：作品详情、章节导览、专题、剧情分享落地页。
- 注意：长列表需要切换紧凑网格，否则浏览大量作品效率低。

## 三、建议落地规则

1. **全面取消渐变**：包括背景光晕、按钮渐变、封面伪渐变、文字渐变、顶部 Hero 底部渐隐。照片上的可读性用局部纯色信息条 / 不透明底 / 图片外排版解决。
2. **颜色只来自两处**：一套固定品牌色 + 作品自身的画面。不要再叠紫粉光。
3. **每页只留一个主行动**：内容页「开始游玩」；工作台「继续创作」；官网「开始创作」。次要入口用文字按钮。
4. **作品是内容，不是装饰**：封面 → 标题 → 一句故事钩子 → 章节/结局 → 行动。把「类型 + 空封面 + 大字母」改为真实帧图或统一的品牌占位。
5. **不在图片上堆多层控件**：收藏、播放、标签最多三处；点击进入详情，主按钮在详情里。
6. **用内容表达互动**：直接写「7 个结局」「你解锁了 2/7」「83% 玩家选择接电话」，而不是只写「AI 互动影游」。
7. **小屏不是缩小桌面**：首屏作品、主 CTA、继续观看优先；导航折叠，作品 2 列，主要触控区 44px。
8. **保留蓝猫识别**：品牌符号、头像、空状态可以使用蓝猫；不要每个模块都放插画猫。

## 四、验收与边界

无头 Chrome 已跑五套桌面（1440px）与手机（390px）测试：

- 搜索「雨夜」→ 1 条结果 → 进入《雨夜来电》详情；
- 收藏 → 「已收藏」；
- 开始游玩 → 选择「接起电话」→ 出现剧情结果；
- 开始创作 → 输入灵感 → 进入创作工作台；
- 手机导航可展开进入工作台；
- 所有方向桌面 / 手机无横向溢出；
- 原型 CSS 渐变数量为 0；
- 测试报告：`test-results/design-directions-20261117/report.json`。

本轮是**视觉与交互方向原型**，不是可上线业务实现。没有连接真实作品数据、用户权限、视频播放器或发布链路；原型图片沿用项目本地素材，只用于设计比较，正式上线应替换为真实作品封面。

## 五、设计判断（更正说明）

> 更正（2026-11-17）：本节初版列出了 Figma / Envato / Awwwards / School of Motion 四个网页作为来源，但这些页面**当时并未实际抓取阅读**，已删除。以下判断来自设计经验与本项目现状审计，不代表引用任何外部调研。

- 用**字体与版式**形成品牌，而不是用渐变。
- 用**破格网格**制造节奏，但保持操作入口稳定。
- 动效服务于「下一幕」「换频道」「推进剧情」，不要漂浮的光斑和无意义粒子。
- 图片真实、有策划，比泛用 AI 氛围图更重要。
