# 编剧工作台功能链路
## 视频转绘功能（未实现）

```text
源视频 → 源剧本 → 目标剧本
```
对应任务阶段：

```text
1. 视频反译：从视频中反推出源剧本，支持分集并行。
2. 设定提炼：从源剧本中提炼人物、世界观、场景、风格等设定总纲。（人工检查点）
3. 逐集对齐：将视频内容与源剧本逐集、逐段、逐镜头对齐。
4. 目标设定：基于用户目标，生成目标设定总纲。（人工检查点）
5. 逐集转绘：根据源剧本、目标设定和对齐关系，生成目标剧本。
```

## 剧本转绘功能
```text
源剧本 → 目标剧本
```
对应任务阶段：

```text
1. 自动拆集：将源剧本中自动拆成多集文本
2. 事实卡提取：逐集分析文本，提取事实卡
3. 设定提炼：根据各集事实卡，统一整理人物称呼，提炼人物、世界观、场景、风格等设定总纲。（人工检查点）
4. 目标设定：基于用户目标，生成目标设定总纲。（人工检查点）
5. 逐集转绘：根据源剧本、源设定、目标设定，生成目标剧本。
```

### 核心用户流程
```text
进入编剧工作台
  -> 查看顶部转绘模式与左侧我的剧本
  -> 新建剧本转绘任务或选择进行中的剧本
  -> 上传剧本并填写转绘需求
  -> 自动拆集
  -> 事实卡提取
  -> 源设定检查点
  -> 目标设定检查点
  -> 逐集转绘
  -> 查看目标剧本并回到编剧工作台
```
