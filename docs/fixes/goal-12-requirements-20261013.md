# 12 项需求核验与发布记录

按用户最新目标执行。参与人员二次编辑权限取代早先“编辑仅管理员”的限制；
删除项目、账号管理和积分操作仍由管理账号控制。

## 功能及本地证据

| 项 | 实现与证据 |
| --- | --- |
| 1 自适应 | 创建、编辑、素材上传、参数、预览等弹窗与工作区缩放隔离；固定关闭/确认区域，内容内部滚动。主画布 6 种视口、48 个弹窗组合，以及 1024×600、768×480、390×700 的项目/资产界面通过实际点击和边界断言。长项目名及多选操作栏可换行。 |
| 2 右键入库 | 画布图片右键“上传到资产库”，填写名称与分类后调用项目域登记接口；复用原存储对象，不移动其他项目素材。浏览器断言登记请求及返回状态。 |
| 3 素材加号 | 生成面板素材行右侧加号直接调用素材库。参考节点 ID 与引用摘要持久保存，不强制新增连线；保存、清理浏览器离线草稿并重载后引用仍在。 |
| 4 节点积分 | 历史版本记录报价及实际积分；成功结果优先显示实际扣费，未结算明确显示预计。服务端读取画布时按任务结算结果协调成本，人民币按 100 积分/元换算。 |
| 5 引用已有节点 | 连线可落到既有节点主体，复用目标节点并同步真正参与生成的参考 ID；不会要求重建节点。 |
| 6 多选批连 | 支持拖动选中节点，也提供统一“拖拽批量连接”点。全选可排除目标自身；重复、反向、环路、不兼容及模型引用上限受统一规则约束。撤销/重做、空白拖动、取消、保存重载和只读权限通过浏览器验证。 |
| 7 修改设置 | 项目参与人员可打开项目设置，修改风格、比例、分辨率、时长与业务模型。后台验证真实工作区权限和字段白名单。 |
| 8 删除上传资产 | 资产库和素材库都有显式删除入口及确认弹窗；采用可恢复的软删除，被画布引用的素材会得到明确拒绝，不删除共享存储对象。 |
| 9 二次编辑 | 项目卡片菜单及项目内入口允许参与人员编辑名称、简介、生成配置；同步修正 API 外层权限分类，避免内层允许但真实子账号仍收到 403。实际认证上下文验证编剧、资产师、分镜师和审核员可编辑，删除及成员管理仍保留给管理员。旧悬停/点击互相取消的菜单逻辑已移除。 |
| 10 批量上传 | 每批最多 100 个文件，自动命名、逐项修改、串行上传、逐项状态与失败重试。重试不重复明确成功的文件；100 个长名称文件的短屏列表可滚动，按钮不越界。 |
| 11 目录/场景上传 | 项目与全局目录分开；上传分类可在本批成功后切换，旧请求不会覆盖新目录，角色读取失败不阻断场景。图片 MIME 兼容与实际 Sharp 解码验证保留。素材和项目目录按分页完整读取。 |
| 12 计费逻辑 | 共享钱包是生成余额源，个人每日额度独立；0 禁止新生成，unlimited 只取消每日限制。旧分配入口改为设置额度，禁止把共享余额转到不用的个人钱包。历史资金可精确收回到 4 位小数积分；有余额/冻结的账号不能直接删除。同步请求通过事务独占冻结，真实并发测试断言只调用一次上游；数据库异常不误报积分不足。Admin/Web-only 启动不重置其他进程的生成任务。 |

## 校验方式

- 最终全量单元、API 与供应商兼容断言：568 个文件、2563 项通过。
- 最后权限链、协作同步和旧测试契约补充回归：11 个文件、74 项通过；类型检查及修改文件零警告 ESLint 通过。
- 精确积分/账号防护：20 个文件、155 项通过。
- 真实 MySQL 计费、退款、幂等和并发：7 个文件、38 项通过。
- 管理台启动隔离：4 项通过。
- 浏览器真实组件、本地模拟接口：不写生产数据、不调用付费生成；截图与日志在忽略的 `test-results/` 中。
- 类型检查、针对修改文件的零警告 ESLint、固定 TOS 守卫、定价目录守卫、API 路由守卫以及生产镜像构建作为发布门槛。
- 构建时以源码内容指纹标记镜像，发布前核对，避免上传过时的候选。

部分测试把大型模块的首次动态导入计入测试时间；本机并行构建时发生过 30 秒冷导入超时。
原断言未放宽，单独重跑在 1.5 秒内通过；全量运行设置 90 秒冷导入预算。
macOS 的云端占位依赖曾阻塞补跑；最终使用依赖版本与 integrity 指纹一致的
本地 Docker 测试环境完成回归，没有挂载密钥文件。旧供应商测试改为验证
当前不支持的供应商会被明确拒绝，未重新启用退役服务。
