# 项目 / 作品层级：6 项边界修复

本次修复此前专项审计确认的 6 个问题。仅本地修改，没有部署，没有访问或
修改生产数据库，也没有调用付费生成、TOS 上传或删除。

| 问题 | 修复 |
| --- | --- |
| 项目菜单靠近屏幕底部时被截断 | 使用既有 `ViewportPopover` 独立视口弹层，空间不足时向上展开；菜单按钮可点击，键盘导航及 Escape 焦点恢复保留。 |
| 搜索后移动作品缺少目标项目 | 完整、分页读取项目目录；搜索只作为展示过滤，单个或批量移动仍使用完整可管理目录。 |
| 带搜索条件的新建链接误报父项目不存在 | 父项目存在性和创建权限以完整目录判断，兼容 `create_work/parent_project_id` 与旧链接字段；真实不存在或权限不足仍拒绝。 |
| 工具箱只加载前 100 个作品 | 复用完整分页读取方法，去重并支持取消。后页失败时不把前页当作完整列表，显示错误及重试，禁止不完整状态下生成。 |
| 新旧作品 ID 列表冲突未拒绝 | 服务层统一校验 ID 和目标字段；按去重、去空白后的集合比较，新旧列表不同返回 400，不读取或更新数据库。不同顺序、相同重复项仍兼容。 |
| 删除与移动交错时回收站作品被移动 | 事务更新同时匹配原父项目、工作区和 `deletedAt=null`；失配返回 409。批量操作中任何一项冲突都会回滚先前更新。 |

同时补充移动接口的 JSON 对象校验，`null`、数组或字符串请求体返回 400，
不再因读取字段产生 500。未新增自动建项目行为，原数据 ID 和业务归属不变。
