# 视频生成：失效节点引用与参考图片尺寸修复

状态：2026-10-15 已部署至备案机 `14.103.65.61` 并完成线上验收；未提交真实付费生成。见 [部署记录](../deployments/beian-seedance-reference-20261015.md)。

## 已确认的原因

- 截图对应的旧画布保存了 6 个生成引用，其中 1 个节点已不存在。调用模型前登记引用失败，没有为该次点击创建视频任务。
- 筷子资源同步失败的两张参考图片实际为 6336×2688；上游明确返回 `Width must be between 300px and 6000px.`，不是视频服务失联或签名过期。
- 排查时备案机四个容器 healthy、没有重启；对最近两条已有任务进行只读上游查询，HTTP 200、`succeeded`，均有视频结果。不将已有任务查询视为新生成实测。

## 修复

### 引用节点

- 显式删除节点、删除组及成员、React Flow 节点删除事件，都移除对应生成引用与摘要，包括没有连线的素材库加号引用；撤销仍能恢复节点和引用。
- 旧数据中的失效引用不会被静默忽略。生成面板显示持续提示与“清除失效引用”，确认后立即保存清理后的配置，保留提示词、其它参数及有效引用顺序，再次点击可正常提交。
- 缺少引用时在前端阻止提交；服务端登记缺失节点改为 HTTP 400 `INVALID_PARAMS`，附带本批次缺失 ID，不再误报接口 404，也不部分登记。
- 失败节点上的直接重试捕获拒绝并选中节点、显示提示，不再产生未处理 Promise 拒绝。
- 生成面板增加防御性最大宽度和非锚定时的最大高度；提示、关闭、生成按钮在小屏可访问。

### 参考图片

- 在筷子 Seedance 最终请求边界统一读取并检查图片；2.0 Pro/Fast/Mini、2.5、首帧、尾帧、多图参考共用处理。
- 超出 300–6000px 边长范围的常规静态图片等比调整为独立副本，6336×2688 调整为 6000×2545；不覆盖或删除原始素材、不裁剪、不拉伸。
- 透明图片保留透明度，按 EXIF 方向处理；极端比例、无法解码、超限文件明确拒绝，不丢弃某张引用后继续提交。
- 请求体无图片的纯文生和筷子 `asset://` 引用不额外读取/上传图片；其它供应商及 Kling 参数不变。
- 下载大小限制 40MB，解码像素限制与网络超时防止无限读取；错误消息不含原始签名 URL。图片预处理失败时不会向视频上游创建任务。
