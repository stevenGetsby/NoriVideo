# 画布与工具箱素材交互修复（2026-10-14）

本轮仅修改、验证本地代码，未部署或修改服务器、业务数据库与 TOS 配置。

## 需求对应

1. 作品资产全选/多选后显示统一的“拖拽已选”入口；拖到生成节点直接成为引用，不要求逐项连线。保留模型上限、只读限制、去重和一次撤销整个批次。
2. 工具箱参考素材分为人物、场景、道具、音色；图片共用模型的总上限，音色仅在支持音频参考的视频模式可用。
3. 通用素材选择器增加资产分类；音色筛选对应真实音频。画布作品资产也增加音色入口。
4. 生成历史刷新使用不缓存的权威请求、显示刷新反馈、手动刷新重载结果预览；失败保留上次列表。素材与生成历史返回可重新签名的存储链接，视频采用播放链接。
5. 删除“我的素材”大图预览里的资产归类编辑下拉；其他资产目录的正常分类功能保留。
6. “素材类型”下拉用于返回相应类型的素材列表，不把视频、图片等文件错误改成其他格式。素材选择弹窗提供底部确定/关闭入口，兼容单选确认与多选一次加入。
7. 工具箱明确分开纯文生、全能参考、图生和首尾帧。纯文生不提交任何参考素材；后端拒绝 `textOnly=true` 与媒体引用矛盾的请求。画布现有全能参考协议保持兼容。旧草稿有参考素材时迁移为全能参考。
8. 批量素材插入只构造一次节点更新、记录一次撤销快照；平移不再每帧重绘整张画布，锚定编辑器与缩放标签限频更新。小屏工具箱使用自然高度的纵向滚动布局。
9. 生成前提交最新草稿并等待保存，再登记引用节点；已删除引用明确提示清除，不静默少传输入。批量登记先检查节点集合，超限明确拒绝，失效素材不复用缓存 ID。错误消息隐藏签名访问参数。

额外修复：页面 120% CSS 缩放时，ReactFlow 原始屏幕坐标转换未考虑界面缩放，导致素材落在节点上却被当作空白处。拖放、居中插入、右键插入与连线创建现在使用统一换算。拖入新引用后同步正在打开的编辑器；素材放在目标旁边，避免覆盖目标。
