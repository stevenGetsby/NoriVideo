# 所有在范围内的项目需求：完成与验证记录

本记录覆盖此前已发布的项目/资产/权限/额度需求、最新画布九项，以及之前未完成的角色音色、导出命名、成员下载目录。已取消的 Minimax H3、持续云同步不重新启用；个人文件清理不属于本次代码发布范围。

## 本次补齐

| 需求 | 完成方式 |
| --- | --- |
| 角色卡音色 | 上传角色图、工具箱生成角色图，以及项目/全局结构化角色都有设置入口。图片角色卡保存经过权限验证的音色素材 ID，支持选择已有音频、上传、试听和解绑。解绑不被旧音频元数据重新“显示为已绑定”。 |
| 批量角色与音色 | 支持同时选择角色图与音频，按文件名配对、逐角色下拉确认。重复/未匹配音频明确拒绝，不任意覆盖同名角色。成功文件在本弹窗失败重试时不重复上传；失败音频可替换，已上传角色名称可修改。 |
| 音色复用 | 视频全能参考、有声模式自动读取角色卡绑定音频；项目/全局结构化角色由服务端按权限解析，复用已索引音频，未索引时读取真实时长。图像、纯文生、首尾帧和明确无声视频不暗中添加音频；超出模型限制先拒绝，不扣费。 |
| 引用与删除保护 | 失效引用明确清除，生成先提交最新草稿并等待保存。音频被角色卡或结构化角色使用时不可删除；绑定与音频删除之间增加版本/事务保护。 |
| 导出名字 | 默认 `机甲三国_测试_视频001_马俊.mp4`，支持 `{project}_{episode}_{generation}_{attempt}次生成_{creator}`。项目题头读取实际父项目；创建者来自生成资料，不使用下载者。新工具箱/画布素材和既有作品视频下载入口都覆盖。长 Unicode 名称按字节控制，保留创建者后缀；旧数据没有可核验次数时明确“未记录”。 |
| 成员固定目录 | Chrome/Edge 的 HTTPS 或 localhost 下由成员亲自选择目录，真实目录句柄持久化到本机 IndexedDB，按账号与作品隔离。工具箱、素材预览、画布、视频增强使用共同目录。换设备不继承授权；不支持时普通下载，不把成员的本地路径当服务器路径执行。重复下载自动改名，不覆盖已有文件。 |
| 最新九项交互 | 多选统一拖入、人物/场景/道具/音色模块、刷新反馈、取消无效归类下拉、类型筛选、确认关闭、纯文生与参考模式分离、批量更新优化、引用 404 时序修复，见 `canvas-toolbox-reference-20261014.md`。未完成或无地址素材不可选作生成引用。 |
| 新发现的小屏问题 | 390px 项目页新建按钮越界、音色页固定宽度、长角色名对弹窗关闭按钮的挤压均已修正并补测。 |
| 本地测试速度 | TypeScript/Vitest 排除 `.runtime` 发布快照与生成产物，避免重复扫描旧代码。云端占位依赖引发的冷导入超时，使用隔离 Docker 的相同版本依赖复核，未放宽业务断言。 |

## 发布规则

服务器 `.env`、`.env.local`、`.deploy.env`、`data/services.prod.json` 与原配置必须逐字节保留。只添加两个可空导出设置字段，不覆盖账号、余额、项目、任务或素材数据。数据库操作前备份，严格 SQL 守卫拒绝其它增删改结构；切换前后执行固定 TOS 守卫和随机对象上传/读取/签名读取/精确删除探测。

测试证明上述功能和已覆盖边缘场景，不是“以后绝对没有任何 bug”的保证。浏览器与供应商协议测试不发起真实付费生成；真实上游服务持续可用性不能由模拟测试保证。是否已部署、候选源码指纹及线上验收以实际部署记录为准。
