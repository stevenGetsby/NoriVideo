# 素材与工具箱 6 项交互修复

## 修改

1. 批量上传全部成功后自动关闭。部分失败保留弹窗和失败原因，重试不重复上传成功项；上传期间仍禁止关闭和改变归属。
2. 作品内素材选择器、工具箱“我的素材”以及画布侧栏默认显示当前作品。收藏、来源、回收站筛选保持当前范围；只有显式选择“全部可访问素材”或其他作品才扩展范围，后台工作区权限不放宽。
3. 创建人改为真实账号/素材创建人下拉选择，按名称精确筛选。共享钱包的管理账号 ID 不再把其他创建人的素材误算成管理员创建；缺少创建人名称的旧记录保留兼容。
4. 资产库与素材库增加勾选、全选和批量删除。入口只给有 `assetWrite` 权限的账号显示；后端再次校验权限、归属与引用，每批最多 200 个本地上传资产。软删除不删除 TOS 文件；任意引用、归属或并发冲突导致整批回滚。批量引用检查只读取一次画布/历史/工作流数据。
5. 素材卡片和大图预览增加重命名，分类上传资产也有入口。名称不能为空或超过 160 个字符，失败保留弹窗，保存成功立即刷新名称。服务端实际返回值为准，旧请求不能覆盖新名称。
6. 工具箱顶部“图片生成 / 视频生成 / 我的素材”改为一个功能下拉；素材页面仍保留归属作品选择。模型配置和生成历史取消旧请求，避免切换作品后被旧结果覆盖。

## 边界修正

- 大图预览使用视口浮层，重命名/确认层高于预览层；不受工作区缩放影响。
- 小屏或短屏素材选择器采用范围下拉、可展开筛选，保留素材展示区域与固定关闭/确认按钮。
- 资产勾选框留在自己的卡片内，工具箱“功能”标签不拆行；资产来源使用原生下拉，长目录不再从容器越界。
- 目录切换清空选择；批量删除只针对当前展示范围中的上传资产，引用保护和只读账号限制保留。
- 上传不再每成功一项就重新请求整套资产列表，结束后统一刷新。

- 原项目创建、编辑、回收站、角色后场景上传、100 文件上传、旧目录响应、批量连线等浏览器回归通过。
