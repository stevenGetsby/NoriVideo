# 登录首页视觉改版

状态：2026-10-15 已部署至备案机 `14.103.65.61` 并完成线上验收。原生产数据和登录服务配置保留。见 [部署记录](../deployments/beian-brand-login-20261015.md)。

## 设计

- 独立的电影工作室入口：按用户反馈改为功能区同款中性深灰黑、蓝色主按钮，大标题、取景框式风景画面与克制的细边框。背景、面板、输入框、文字和主题色直接复用工作台 `--fos-*` token，不再保留墨绿或奶油金主题。
- 左侧品牌叙事与故事/资产/镜头流程，右侧聚焦账号登录。小屏优先表单，页面自然滚动，不继承工作台固定定位和 120% 缩放。
- 保留账号密码登录、工作区角色跳转和独立 Admin 入口，不增加虚假的扫码、第三方登录、自助注册或忘记密码接口。
- 增加密码显隐、大写锁定提示、原生焦点约束的指南弹窗、防重复提交和账号纯空格校验；密码本身不做 trim。
- 错误反馈区分账号错误、限流、服务异常及网络错误。中英文登录页均有边界覆盖。
- 没有读取生产项目的私有图片。设计用图像工具两次返回“图片生成失败，请稍后重试”，未产出可用图片；主视觉改用本地托管的 Pexels 照片，来源与处理说明位于 `public/auth/ASSET-CREDITS.md`，不宣称为原创 AI 场景。

- 完整 TypeScript 检查与修改 TS/TSX 文件零警告 ESLint 通过，固定 TOS 守卫通过。
- 隔离检查目录曾出现复制嵌套的重复目录，已精确清除临时副本后重新完整检查；未删除工作区源码或业务数据。
- 浏览器认证响应为模拟，不使用真实凭据、不调用业务数据库或生成服务；生产页面仍使用原 NextAuth。
- 结果与桌面/手机截图位于忽略的 `test-results/auth-redesign/`。

## 本地查看

`node scripts/auth-home-preview.mjs --serve` 启动仅绑定 `127.0.0.1:4318` 的独立设计预览，认证是模拟的，请勿输入真实账号密码。完整浏览器回归使用 `node tests/browser/auth-home.browser.mjs`。

除本次统一品牌标志外，没有修改工作台业务布局或平台管理登录逻辑。后续部署应先确认设计，并继续遵守备案机目标、受保护配置、固定 TOS 守卫/探测及生成队列排空规则。
