# NoriVideo 无限画布与 FrameOS 对照审计

审计日期：2026-07-18  
审计对象：NoriVideo 无限画布入口、前端交互、生成链、持久化、3D 导演台、权限与运行状态  
对照来源：FrameOS 本地 App 运行时只读检查、已保存 Bundle 证据、NoriVideo 源码与自动化回归  

## 1. 最终结论

此前用户反馈的“没有画布进入入口”已经在当前源码中修复。静态路由审计确认：全局导航、折叠导航、当前项目侧栏、非画布项目页 Header、项目概览页头、项目卡片和项目卡菜单都指向真实页面；全局 Hub 与项目工作台都支持画布深链，不是占位按钮。

在 FrameOS 当前只读证据能确认的范围内，NoriVideo 源码已覆盖主画布、节点/连线、分组、工作流、素材、生成器、历史恢复和 3D 导演台，并为保存、任务、revision、冲突、离线草稿、worker 终态回写和权限提供真实后端。静态覆盖和自动化测试不等同于所有外部服务、输入设备和写入操作都已端到端验收。

本审计不把“未执行真实付费模型任务”包装成已验证。FrameOS 云端始终只读；NoriVideo 本轮也没有消耗图片、视频、音乐、音效、TTS 或 3D 外部服务额度。因此准确表述是：

- 已完成证据可见功能的前端、后端与交互复刻。
- 已完成本地 API、队列、持久化和失败恢复验证。
- 外部模型成功率、触控手感、系统剪贴板权限仍需真实环境验收。

本文也不声称已经完成像素级 1:1。当前视觉值以 FrameOS 实机截图和 bundle 证据为基线完成了源码级对齐，最终观感仍须在新版生产构建中逐页截图比对。

## 3. 主画布功能矩阵

### 3.1 视口与选择

- 0.08–4 倍缩放、滚轮平移、Meta/Ctrl + 滚轮缩放、触控板 pinch。
- Space + 左键、中键、右键拖动画布；右键拖动后不会误弹菜单。
- 小地图开关、缩小、放大、适应画布、独立重置视图。
- 框选、部分相交选择、多选、全选、对齐和成组。
- 按连线横向分层、按连线纵向分层、网格去重叠整理。
- 方向键移动 5px，Shift + 方向键移动 50px；移动后重算组归属。
- 视口随画布文档持久化；只读账号不会写入视口。

### 3.2 节点与连线

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 文本、图片、视频节点 | 已实现 | 新建、上传、生成、替换、历史 |
| 3D 模型节点 | 已实现 | GLB/GLTF 上传、预览、生成 |
| 3D 导演台节点 | 已实现 | 独立场景文档与截图回传 |
| 音频节点 | 兼容实现 | 可上传/素材导入/生成；空白新建与原版一致保持禁用 |
| note 节点 | 兼容实现 | 旧文档按文本渲染；不暴露新建入口 |
| 生产节点 | 已实现 | 剧本、分镜、Panel、视频只读投影 |
| 创建连线 | 已实现 | 拖拽连接，空白落点可创建节点并自动连接 |
| 连线校验 | 已实现 | 自连、重复、组连接和媒体不兼容会拒绝 |
| 删除连线 | 已实现 | 选中删除或右键删除 |

普通节点右键菜单与原版明确对齐为：复制、创建副本、重新生成、删除。缺少提示词或模型时“重新生成”禁用。NoriVideo 另外保留下载、预览和替换等节点内增强入口。

### 3.3 剪贴板、上传与菜单

- 复制、剪切、粘贴、原地复制、Alt/Option 拖拽复制。
- 内部 `NORI_CANVAS` 剪贴板支持跨画布粘贴。
- 系统文本可粘贴为文本节点；系统图片、视频、音频和 GLB 可上传为节点。
- 右键位置新建、上传和粘贴会落在点击位置。
- 多文件上传最多 100 个，使用 `allSettled` 保留部分成功结果。
- 菜单会约束在视口内，Escape 和外点可关闭。

### 3.4 分组、素材与工作流

- 创建组、拖组带动成员、解组、删除组及成员。
- 组颜色、宫格/横向/纵向排列、复制和保存工作流。
- 工作流模板支持搜索、拖入、双击加载、重命名、二次确认删除。
- 项目资产支持搜索、类型过滤、拖入、双击和按钮添加。
- 本地上传素材支持行内与右键重命名、二次确认删除；生产资产不会被误删。
- 素材库选择器支持跨类型多选，最多一次加入 100 个。

## 4. 生成器与任务链

### 4.1 图片

- 比例：`16:9 / 9:16 / 21:9 / 4:3 / 3:4 / 1:1`。
- 分辨率：`1K / 2K / 4K`。
- 质量：低、中、高。
- 数量：1、2、4 张。
- 模式：普通生成、聚焦、连续故事版。
- 720 全景新任务统一使用 `21:9`；旧文档的 `2:1` 仅在读取/API 边界兼容并升级。
- 涂抹改图会把源图和独立 `maskMaterialId` 分开提交，只允许一个源图；服务端拒绝客户端直传的 `maskImage` 和混入普通参考图的蒙版。
- OpenAI 兼容模型使用真实 `images.edit({ image, mask })` 契约：黑白蒙版按“白色为透明编辑区、黑色为保留区”转换，已有 alpha 蒙版保留 alpha，并自动对齐源图尺寸；空蒙版会被拒绝。

### 4.2 视频

- 表面模式只保留“全能参考 / 首尾帧”，旧 `image` 值仅作为文档兼容别名。
- 比例：`16:9 / 9:16 / 21:9`。
- 分辨率：`480p / 720p / 1080p / 4K`，实际可选项按模型能力收敛。
- 时长：4–15 秒整数。
- 有声视频仅在模型声明支持时显示/提交。
- 首尾帧强制恰好两张图片，并立即清除视频、音频和多余图片引用。

### 4.3 引用、历史和能力契约

- `@资产名` 编辑、蓝色 mention、`referenceNodeIds` 和素材 ID 同时保存。
- 输入数量、媒体类型、音频总时长和必填字段由模型 `inputSchema` 前后端共同校验。
- 生成历史保存模式、模型、比例、质量、时长、提示词和参考素材摘要。
- 文本生成与故事版规划使用持久 Task；刷新后继续轮询和物化结果。
- 图片、视频、音频使用稳定幂等键、服务端节点绑定和 worker 终态投影。
- worker 先完成、节点后绑定时会重新读取资产并认领终态，不丢结果。
- 连续读取状态失败会显示警告但保持 RUNNING 并继续重试；恢复后自动清警告，不伪造 FAILED。

### 4.4 音频和 3D 生成

- 配音使用百炼 TTS；音乐接入 FAL Stable Audio 2.5（1–190 秒、1 秒步进），音效接入 FAL ElevenLabs SFX v2（0.5–22 秒、0.5 秒步进）。只有模型能力、执行适配器和服务密钥同时可用时才开放对应模式。
- FAL 音频提交为持久 Task：保存外部 requestId、轮询恢复、下载到自有存储、登记项目素材，并把成功或最终失败投影回 Canvas 节点；兼容 provider 返回字符串 URL 或 `{ url }` 两种音频结果。
- 上传音视频会通过 ffprobe 保存时长元数据。
- 3D 支持标准/低模、贴图开关、无/A/T 姿势、外部 taskId 恢复、GLB 2.0 校验、自有存储和素材登记。
- 本轮未执行真实付费图片、视频、音频或 3D 任务。

## 5. 保存、历史、离线与冲突

- 编辑后约 800ms 合并变更。
- 首次/恢复场景使用完整 document PUT；常规编辑使用增量 ops。
- ops 包含 node upsert/delete、edge add/delete 和 canvas metadata 更新。
- `expectedRevision` 条件写入；冲突返回 409。
- 每次保存写历史快照，最多保留 40 条，可恢复。
- 本地撤销/重做与服务端 revision 分离，默认保留 80 个编辑快照。
- IndexedDB 按账号/项目/画布命名空间保存完整草稿、pending ops、最后 revision 和错误。
- 失败退避为 3/8/20/45/60 秒，重新联网后继续提交。
- 再次进入时明确选择本地或服务器版本，不静默覆盖。
- 多标签可加载服务器版本或执行终态感知浅合并。

浅合并仍不是 CRDT：同 ID 普通节点以本地为主，服务器终态可替换本地 RUNNING，双方独有节点和边均保留。实时多人协作在 FrameOS 当前证据中也未证实，不列为本轮 1:1 门槛。

## 6. 3D 导演台

### 6.1 场景与对象

- Three.js 真实场景；素材库模型、本地 GLB/GLTF、内置素体、群众和几何体。
- 场景树搜索、隐藏、锁定、复制、删除和组级操作。
- 20 种姿势、关节微调、GLTF 骨骼兼容提示。
- V/R/S 切移动/旋转/缩放；S 仅在选中对象或场景整体时切换缩放，未选中时仍用于导演视角后退；Gizmo 可操作对象和机位。
- 网格吸附、跨模型表面吸附与 fallback。
- 全景、天空颜色、网格、地面、全景半径和场景整体平移/旋转/缩放。

### 6.2 视角与机位

- 独立导演视角和机位视角。
- 12 个固定机位，加“保存当前导演视角”。
- 机位位置、注视/跟随、FOV、roll 和实时预览。
- 左侧场景树或视口点击机位会选中并进入可拖动状态。
- W/A/S/D 按当前视角移动对象、场景或机位；无选中时移动导演视角；Q/E 升降。
- 原版同时把 `S` 写成“缩放”和“后退”。NoriVideo 按选择上下文消歧：选中对象或场景整体时 `S=缩放`，未选中时 `S=导演视角后退`；帮助与 tooltip 已明确说明。

### 6.3 截图与独立文档

- 截图比例：Auto、21:9、16:9、4:3、1:1、3:4、9:16。
- 当前机位、全部机位与导演视角截图；导演截图会自动创建机位。
- 截图先进入暂存区，按 cameraId/机位名分组，支持预览、多选和发送到画布。
- 显示成功/失败明细；退出期间不会让异步截图或上传回写已卸载组件。
- 右栏提供“属性 / 摄像机截图”双 Tab。
- 3D 场景使用独立 GET/PUT 文档 API、独立 revision、409 合并和旧嵌入场景回填。
- Three.js 材质、纹理、骨骼、网格和预览 renderer 在替换/退出时释放。
