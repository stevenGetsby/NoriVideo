# 账号管理与功能区权限

## 账号结构

系统不开放注册，账号分为三层：一个平台 Admin、多个管理账号，以及每个管理账号下的多个角色子账号。平台管理与内容生产使用两套互相隔离的前端入口。

| 账号类型 | 读取团队内容 | 功能区权限 | 账号与系统管理 |
| --- | --- | --- | --- |
| 平台 Admin | 不进入 NoriVideo | 不在生产端操作 | 管理直属管理账号 |
| 管理账号 | 自己的工作区 | 剧本、资产、分镜、工具箱、无限画布全部开放 | 管理自己的子账号 |
| 角色子账号 | 所属管理账号的全部项目与资产 | 由管理账号逐项勾选 | 否 |

子账号的“角色名称”是可自由填写的展示信息，不参与鉴权。真正的授权来源是账号保存的功能区权限：`scriptWrite`、`assetWrite`、`storyboardWrite`、`toolboxUse` 和 `canvasWrite`。编剧、资产师、分镜师只作为创建账号时的一键填充模板，选择模板后仍可逐项调整；同一账号可以同时负责多个功能区，也可以只保留团队只读权限。

## 账号树与工作区数据范围

- `super_admin` 是平台 Admin；现有安装中的 `xyz` 会升级为该角色。
- `admin` 是管理账号，通过 `parentAccountId` 归属于平台 Admin。
- 角色子账号通过 `parentAccountId` 归属于一个管理账号；底层 `writer`、`asset`、`storyboard` 值只用于兼容旧数据和快捷模板。
- 管理账号的数据范围是自身用户 ID；平台 Admin 不通过 NoriVideo 前端进入生产工作区。
- 子账号通过 `workspaceOwnerId` 归属管理账号。
- 子账号通过认证后，服务端保留真实 `actorId` 用于功能区鉴权，并将数据查询范围切换为管理账号 ID。
- 因此子账号读取的是同一工作区的项目、资产、任务、余额和模型配置，而不是一个空的个人空间。
- 写请求先按数据库中的真实功能区权限授权，再使用工作区 ID 做项目/资产所有权校验。

## 会话与账号状态

- `disabled` 账号不能登录，已有会话的下一次请求也会立即被拒绝。
- 重置密码会递增 `sessionVersion`，此前签发的 JWT 会立即失效。
- 修改角色名称或功能区无需等待 JWT 过期；会话与每次 API 请求都会从数据库重新读取当前配置。
- 平台 Admin 不能停用、改角色或删除，也不能在独立平台里创建或维护角色子账号。
- 管理账号只能由平台 Admin 停用；管理账号停用后，其全部子账号也会被拒绝登录和访问接口。
- 角色子账号只能由所属管理账号修改角色名称、功能区、状态、密码和删除。

## 两套前端入口

- 工作台和平台 Admin 使用两个独立 Web 进程及端口；生产默认分别是 `80` 与 `8080`。
- `http://<host>:8080/{locale}/admin/signin`：平台 Admin 的独立登录页。
- `http://<host>:8080/{locale}/admin/accounts`：独立平台控制台，只显示和 CRUD 直属管理账号以及工作区汇总数字；不使用 NoriVideo 顶栏、侧栏或生产工作台。
- `/{locale}/auth/signin`：NoriVideo 登录页，仅允许管理账号和角色子账号登录；平台 Admin 会被服务端拒绝，并通过页面入口前往独立管理端口。
- `/{locale}/account-management`：集成在 NoriVideo 内的子账号管理页，只允许管理账号访问，只显示当前管理账号自己的角色子账号。
- 平台 Admin 访问 NoriVideo 主工作台时会被送回独立控制台；NoriVideo 侧栏只向管理账号显示“子账号管理”。
- 两个入口使用不同的会话 Cookie。浏览器 Cookie 不按端口隔离，因此不能共用默认 NextAuth Cookie 名称；平台 Admin 账号也会在服务端拒绝从工作台端口登录，管理账号和角色子账号反向同理。

## 账号积分

- 每个账号独立保存“金币”和“积分”，新建账号以及既有账号迁移后的默认值均为 `0`。
- 页面右上角只显示当前实际登录账号的数值，不跟随共享工作区切换。
- 平台 Admin 可为直属管理账号充值；管理账号可向自己的角色子账号分配或收回积分；子账号无权修改。
- 可用积分统一以 `UserBalance` 账本为准，充值、分配、收回、消费与退款都写入不可重复入账的积分流水。

## 管理接口

- `GET /api/admin/accounts`：平台 Admin 只读取直属管理账号、子账号数量和工作区汇总；管理账号只读取自己及自己的角色子账号明细。
- `POST /api/admin/accounts`：平台 Admin 只能创建直属管理账号；管理账号只能创建自己工作区的角色子账号，并设置角色名称与功能区。
- `PATCH /api/admin/accounts/:userId`：平台 Admin 只能修改直属管理账号；管理账号只能修改自己的直属角色子账号。账号归属不可在此转移。
- `DELETE /api/admin/accounts/:userId`：安全删除账号；管理账号有子账号或账号仍拥有业务数据时拒绝删除，避免级联误删。
- `POST /api/auth/register`：固定返回 403。

所有管理接口都在服务端同时校验角色和账号树归属，不能通过直接调用 API 越级管理其他工作区。内容接口继续通过请求级隔离上下文按 HTTP 方法和资源域执行读写权限。
