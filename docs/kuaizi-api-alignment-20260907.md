# 筷子兼容接口对齐（2026-09-07）

依据用户提供的《视频生成兼容接口文档》v1.2、《素材资产管理兼容接口文档》v1.0 与《丽帧独立 EP（kzep）使用文档》v1.0。

## 本次变更

- Seedance Mini / 2.5 按实际输出时长与分辨率结算；返回 token 不改变价格模式。Pro / Fast 继续按实际 token 结算。
- 用量记录增加输出计费元数据，避免管理台默认按 720p 计算 480p 输出。
- `expired` 作为失败终态处理；成功结果保留时长、分辨率、比例、帧数、帧率、音频开关、seed、尾帧地址与实际 token，优先使用 `kz_video_url`。
- 素材客户端按实际模型路由选择：筷子使用 `ApiKey` + asset Action 入口；Ark 保留原签名客户端；TOS 配置不变。
- 素材组与素材按项目、服务端点、提供商和账号隔离。长整型素材 ID 保持字符串，`asset://` 不经过 TOS 签名，只有 Active 且归属匹配的素材可用于生成。
- 画布视频编辑使用公共持久化轮询链路，已有 externalId 时恢复轮询，不重新提交；最终输出参数传回计费。
- 禁止把筷子的失败任务回退到 Ark 账号发起生成。

## 数据库与兼容性

新增迁移 `20260907090000_service_usage_output_metadata`，仅增加可空列：

- `service_usage_records.metadata`：JSON。
- `character_appearances.seedanceAssetScope`：素材提供商/账号归属标识。

已有用量记录未包含实际分辨率，无法凭空恢复历史参数；旧记录继续使用原回退规则。
旧角色素材未记录可核验的账号归属，需重新注册后使用；不能直接将 Ark 素材 ID 当作筷子素材 ID。
范围内验证使用模拟 API，不消耗生成额度，不代表上游账号实测成功。

## 未开启

- Seedance 2.5 1080p：已有请求参数支持，但缺少确定报价，仍不开放业务选项。
- 独立 EP：尚未分配真实 EP 与计费型号映射，未启用 `Kzep` 或 `kzep_...` 路由。
- 可选 `web_search` 工具未增加。

本轮只更新代码并验证本地，不部署任何服务器。后续部署须保留服务器密钥文件，先通过固定 TOS 守卫，再执行上传/读取/删除探测。
